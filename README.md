# Taller de R

Materiales del workshop Taller de R (nivel introductorio) de la Escuela de Verano en Métodos Mixtos (2017).

## Estructura

La carpeta **Modulos** contienen las diapositivas de la parte teórica. En la carpeta **Codigos** están los archivos asociados a los ejercicios prácticos. Las bases de datos se encuentran en el Dropbox de la Escuela.
