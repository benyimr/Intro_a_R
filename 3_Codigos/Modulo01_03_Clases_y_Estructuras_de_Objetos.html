Clases Atómicas de Objetos

Existen en R seis clases básicas de objetos. Estas clases primarias son también llamadas atómicas. Estas clases atómicas son:

Atómica Modo Almacenamiento Descripción
logical logical logical Valores lógicos: TRUE, FALSE
integer numeric integer Número enteros (sin decimales)
double numeric double Números con decimales
complex complex complex Números complejos
character character character Caracteres (cadenas de letras/símbolos)
raw raw raw Valores brutos

Existen comandos útiles para chequear lo anterior. El más común es utilizar class() para identificar la clase de un objeto. Tal como se deduce de la tabla anterior, el modo de almacenamiento puede ser distinto.


#Lógico
a <- TRUE
a
## [1] TRUE
class(a)
## [1] "logical"

#Numérico o Doble (incluye decimales)
b <- 4.5
b
## [1] 4.5
class(b)
## [1] "numeric"

#Entero: se generan usando el sufijo L
c <- 3
c
## [1] 3
class(c)
## [1] "numeric"

c <- 3L
class(c)
## [1] "integer"

#Complejo: números complejos con el sufijo i
d <- sqrt(-2) #Arroja un error, ya que la operación no está definida en los Reales
## Warning in sqrt(-2): Se han producido NaNs

d <- sqrt(-2i)
d
## [1] 1-1i
class(d)
## [1] "complex"

#Caracter o Cadena: conjunto de letras: se generan con comillas
e <- "Hola"
e
## [1] "Hola"
class(e)
## [1] "character"

f <- "45"
f
## [1] "45"
class(f)
## [1] "character"

Se puede distinguir entre la class() ,como propiedad de un objeto que determina como las funciones operan con él (no es una clasificación completa), del mode()que corresponde a un sistema de clasificación de objetos según su estructura básica. Aún más, existe un modo específico para su almacenamiento al momento de crear objetos.
